强化学习的数学原理(4) Policy Gradient 和 Actor-Critic 方法

用带参数的函数表示策略

之前我们一直在研究如何估计状态或动作的价值，再利用价值来改进策略，现在开始我们则研究能否直接用一个带函数的参数表示策略，再通过梯度优化这个函数？

之前学过的策略表示为 $\pi(a\mid s)$ ，表示在状态 $s$ 下选择动作 $a$ 的概率，这就是 Tabular Policy（表格型策略）。它可以直接查表，获得某个动作的概率，也可以直接修改表中的概率，改进策略。

但随着状态数量增加，策略表也会越来越大，对于连续状态空间，这种方式尤其不方便。因此我们可以使用参数化函数表示策略，即：

\[ \pi(a\mid s,\theta)\]

其中，$s$ 表示当前状态，$a$ 表示候选动作，$\theta$ 表示策略函数的参数。策略不是保存每个状态对应的动作概率，而是通过共享的参数 $\theta$ 计算概率。

对于参数化策略来说我们需要定义一个标量目标函数，然后寻找能够最大化该目标的参数。为什么我们需要这样一个函数？因为之前优化的是单个状态对应的价值，而现在要调整的是整组共享参数 $\theta$。改变参数后，多个状态下的动作概率都可能发生变化。所以我们需要一个统一的指标来评价整个策略。

Policy Gradiant 的核心思想在于梯度上升，因为我们需要最大化 $J(\theta)$:

\[ \theta_{t+1}=\theta_t+\alpha\nabla_\theta J(\theta_t)\]

评价指标的设计

Average State Value (平均状态价值)

既然我们要通过梯度上升最大化参数 $\theta$，那么究竟应该最大化什么？这里我们引入第一个评价指标：Average State Value。之前我们学过状态价值函数，如下:

\[ V^\pi(s)=\mathbb E_\pi[G_t\mid S_t=s]\]

它描述的是：从某个状态 $s$ 出发，按照策略 $\pi$ 行动，未来累计折扣奖励的期望。但是现在我们需要评价的是整个策略的好坏，而不是某一个状态的好坏。因此我们定义：

\[ \bar V_\pi=\sum_{s\in\mathcal S}d(s)V^\pi(s)\]

$\bar V_\pi$ 表示所有状态价值的加权平均。要求权重满足：

\[ d(s)\geq0,\qquad \sum_{s\in\mathcal S}d(s)=1\]

因此 $d(s)$ 也可以解释为状态的概率分布。我们可以将它转化为向量形式或期望形式，如下：

\[ \sum_s d(s)V^\pi(s)=d^TV_\pi=\mathbb E_{S\sim d}[V^\pi(S)]\]

状态分布有两种情况，如下

一、状态分布与策略无关。这其中又有两种情况，第一种是所有状态同等重要，即均匀分布：

\[ d_0(s)=\frac{1}{|\mathcal S|}\]

第二种是只关心一个初始状态：假设机器人每次训练都从固定状态 $s_0$ 开始，那么我们只关心从 $s_0$ 开始能拿多少累计奖励，那么选择

\[ d_0(s)=\begin{cases}1,&s=s_0\\0,&s\neq s_0\end{cases}\]

代入平均状态价值:

\[ \begin{aligned}J(\theta)&=\sum_s d_0(s)V^{\pi_\theta}(s)\\&=\boxed{V^{\pi_\theta}(s_0)}\end{aligned}\]

如果任务总是从固定初始状态开始，我们可以直接把该初始状态的价值作为策略优化目标。如果每个 Episode 的初始状态并不固定，也可以使用一个固定的初始状态分布 $d_0$。

二、状态分布依赖策略。，其定义如下：

\[ d(s)=d_\pi(s)\]

其中 $d_\pi(s)$ 表示按照策略 $\pi$ 长期运行时，对应的平稳状态分布。它满足如下条件：

\[ d_\pi^TP_\pi=d_\pi^T\]

因此，平均状态价值可以写成：

\[ J(\theta)=\sum_s d_{\pi_\theta}(s)V^{\pi_\theta}(s)\]

Average Reward (平均单步奖励)

Average Reward 的定义如下：

\[ \bar r_\pi=\sum_{s\in\mathcal S}d_\pi(s)r_\pi(s)\]

这其中有三个不同的概念需要区分：

1.$r(s,a)$：状态—动作的期望即时奖励

\[ r(s,a)=\mathbb E[R_{t+1}\mid S_t=s,A_t=a]\]

2.$r_\pi(s)$：状态下的平均即时奖励

在状态 $s$ 下，策略可能选择不同的动作，所以：

\[ r_\pi(s)=\sum_{a\in\mathcal A}\pi(a\mid s)r(s,a)\]

3.$\bar r_\pi$：整个策略的长期平均单步奖励。

不同状态出现的频率也不同，因此还需要对状态求平均：

\[ \bar r_\pi=\sum_s d_\pi(s)r_\pi(s)\]

其中 $d_\pi(s)$ 是策略对应的平稳分布。

我们还可以从另一种角度出发定义 Average Reward，那就是长期时间平均奖励。

假设智能体按照固定策略运行，不断获得奖励：

\[ R_1,R_2,R_3,\ldots\]

我们记录前 $n$ 步的平均奖励：

\[ \frac{R_1+R_2+\cdots+R_n}{n}\]

如果运行时间足够长，就得到如下定义：

\[ \bar r_\pi=\lim_{n\to\infty}\frac{1}{n}\mathbb E_\pi\left[\sum_{k=1}^{n}R_{t+k}\mid S_t=s_0\right]\]

直观理解就是机器人长期运行时，平均每一步能获得多少奖励。

这两种定义是等价的:

\[ \boxed{\lim_{n\to\infty}\frac1n\mathbb E_\pi\left[\sum_{k=1}^nR_{t+k}\mid S_t=s_0\right]=\sum_s d_\pi(s)r_\pi(s)}\]

$\bar r{\pi\theta}$ 实际上也是参数 $\theta$ 的函数。

于是我们可以定义：

\[ J(\theta)=\bar r_{\pi_\theta}\]

目标就是：

\[ \theta^*=\arg\max_\theta J(\theta)\]

通过梯度上升更新策略：

\[ \theta_{k+1}=\theta_k+\alpha\nabla_\theta J(\theta_k)\]

这就是 Policy Gradient 的基本思想。

策略梯度定理

策略梯度定理公式如下：

\[ \nabla_\theta J(\theta)=\sum_{s\in\mathcal S}\eta(s)\sum_{a\in\mathcal A}\nabla_\theta\pi_\theta(a\mid s)q_\pi(s,a)\]

这个公式告诉我们应该如何综合各状态、各动作的价值和概率梯度，确定参数 $\theta$ 的更新方向。我们将这个公式改写为期望形式：

\[ \nabla_\theta J(\theta)=\mathbb E\left[\nabla_\theta\ln\pi_\theta(A\mid S)q_\pi(S,A)\right]\]

这样我们就不用遍历所有状态和动作计算每一个状态-动作对的价值，而只是采集 $N$ 个状态-动作样本求一个平均值。

这里引入一个数学技巧 —— 对数导数技巧：

\[ \frac{d}{dx}\ln f(x)=\frac{f'(x)}{f(x)}\]

对于多维参数 $\theta$，同样有

\[ \nabla_\theta\ln\pi_\theta(a\mid s)=\frac{\nabla_\theta\pi_\theta(a\mid s)}{\pi_\theta(a\mid s)}\]

对此，两边同乘 $\pi_\theta(a\mid s)$ 就可以得到

\[ \nabla_\theta\pi_\theta(a\mid s)=\pi_\theta(a\mid s)\nabla_\theta\ln\pi_\theta(a\mid s)\]

我们将这个等式带入策略梯度公式就可以得到

\[ \begin{aligned} \nabla_\theta J =& \sum_s\eta(s) \sum_a\pi_\theta(a\mid s)\\ &\qquad\cdot \nabla_\theta\ln\pi_\theta(a\mid s) q_\pi(s,a) \end{aligned}\]

然后我们将对动作求和改成期望，可以得到

\[ \nabla_\theta J = \sum_s\eta(s) \mathbb E_{A\sim\pi_\theta} \left[ \nabla_\theta\ln\pi_\theta(A\mid s) q_\pi(s,A) \right]\]

再把状态求和也改成期望，就可以得到

\[ \nabla_\theta J = \mathbb E_{\substack{S\sim\eta\\A\sim\pi_\theta}} \left[ \nabla_\theta\ln\pi_\theta(A\mid S) q_\pi(S,A) \right]\]

接下来进行梯度上升即可。为了保证网络的输出是合法的动作概率，我们还需要经过一层 softmax 将离散值转化为 0 - 1 之间的值。

QAC

Actor-Critic 的核心思想是：Actor 负责学习策略、选择动作；Critic 负责估计动作价值，并用估计结果指导 Actor 更新。

之前在学习策略梯度时，我们已经知道：

\[ \nabla_\theta J(\theta)=\mathbb E\left[\nabla_\theta\ln\pi_\theta(A\mid S)q_\pi(S,A)\right]\]

利用随机梯度上升就可以得到：

\[ \theta_{t+1}=\theta_t+\alpha_\theta\nabla_\theta\ln\pi_\theta(a_t\mid s_t)q_\pi(s_t,a_t)\]

但我们通常不知道真实的 $q_\pi(s_t,a_t)$，所以必须估计它。我们可以将这个过程拆分成两部分：Actor 获取环境状态并与环境交互，使用策略梯度更新参数；Critic 估计 $q(s,a,w)$，计算动作价值，提供给 Actor 做价值估计。

QAC 每个时间步做两件事：更新 Critic 的参数 $w$，利用 Critic 估计的 Q-value 更新 Actor 的参数 $\theta$。

Step 1：Actor 选择动作。根据当前策略得到机器人执行动作，然后得到下一步的状态和奖励，再按照同一策略选择下一动作。这里用的就是 SARSA + Function Approximation。

Step 2：Critic 更新。我们先计算 SARSA 的 TD Error，然后更新 Critic 参数。

\[ \delta_t= r_{t+1} +\gamma q(s_{t+1},a_{t+1},w_t) -q(s_t,a_t,w_t)\]
\[ w_{t+1} = w_t+ \alpha_w\delta_t \nabla_w q(s_t,a_t,w_t)\]

Step 3：Actor 更新。Critic 更新之后，我们可以用它预测当前的动作价值：$q(st,a_t,w{t+1})$，再代入策略梯度

\[ \theta_{t+1} = \theta_t+ \alpha_\theta \nabla_\theta\ln\pi_{\theta_t}(a_t\mid s_t) q(s_t,a_t,w_{t+1})\]

因此，Critic 负责提供学习信号，Actor 利用这个信号调整动作选择概率。

Baseline Invariance (基线不变性)

之前在学习 QAC 的时候， Actor 的策略梯度为：

\[ \nabla_\theta J(\theta) = \mathbb E\left[ \nabla_\theta\log\pi_\theta(A\mid S) Q^\pi(S,A) \right]\]

现在我们可以在 Q-Value 后减去一个只与状态有关的函数 $b(S)$:

\[ \nabla_\theta J(\theta) = \mathbb E\left[ \nabla_\theta\log\pi_\theta(A\mid S) \left(Q^\pi(S,A)-b(S)\right) \right]\]

并且只要 Baseline 不依赖当前采样动作，减去它就不会改变策略梯度的期望，且会改变梯度估计的方差。

为了更好的降低方差，理论上最优的 Baseline 是

\[ b^*(s)= \frac{ \mathbb E_{A\sim\pi_\theta} \left[ \left\|\nabla_\theta\log\pi_\theta(A\mid s)\right\|^2 Q^\pi(s,A) \right] }{ \mathbb E_{A\sim\pi_\theta} \left[ \left\|\nabla_\theta\log\pi_\theta(A\mid s)\right\|^2 \right] }\]

但是这个式子十分复杂，需要计算涉及动作概率梯度的加权期望，因此我们用一个更简单的 BaseLine

\[ b(s)=\mathbb E_{A\sim\pi_\theta}[Q^\pi(s,A)] = V^\pi(s)\]

也就是说选择状态价值函数作为 Baseline。它通常是一个实用、有效的选择，但不保证是严格意义上的最优方差 Baseline。

A2C

A2C 的核心思想是用 Advantage 代替 Q-value 更新 Actor，再用 TD Error 近似 Advantage，从而只需要一个状态价值 Critic。

接下来我们从 QAC 过渡到 A2C，之前 QAC 的 Actor 更新公式是：

\[ \theta_{t+1} = \theta_t+ \alpha_\theta \nabla_\theta\ln\pi_{\theta_t}(a_t\mid s_t) Q^\pi(s_t,a_t)\]

现在引入状态价值作为 Baseline：

\[ b(s)=V^\pi(s)\]

于是定义 Advantage：

\[ A^\pi(s,a)=Q^\pi(s,a)-V^\pi(s)\]

Actor 更新变成：

\[ \theta_{t+1} = \theta_t+ \alpha_\theta A^\pi(s_t,a_t) \nabla_\theta\ln\pi_{\theta_t}(a_t\mid s_t)\]

进一步计算可以得到

\[ \theta_{t+1} = \theta_t+ \underbrace{ \frac{\alpha_\theta A^\pi(s_t,a_t)} {\pi_{\theta_t}(a_t\mid s_t)} }_{\text{带符号的更新系数}} \nabla_\theta\pi_{\theta_t}(a_t\mid s_t)\]

因此，advantage 会影响更新幅度：Advantage 大于 0：沿提高该动作概率的梯度方向更新。Advantage 小于 0：沿降低该动作概率的方向更新。Advantage 接近 0：该样本对 Actor 的更新较小。

我们现在已经知道：

\[ A^\pi(s_t,a_t)=Q^\pi(s_t,a_t)-V^\pi(s_t)\]

但是这存在一个问题：如果要直接计算 Advantage，就需要同时知道 Q-Value 和 V-value。根据贝尔曼期望方程，可以发现 Advantage 是可以使用 TD Error 代替的，可以减少计算量。

A2C 的完整训练流程如下：

Step 1：Actor 采样动作。根据当前策略执行动作得到奖励和下一状态。

Step 2：计算 TD Error。使用 Critic 计算近似 Advantage：

\[ \delta_t= r_{t+1} +\gamma V_{w_t}(s_{t+1}) -V_{w_t}(s_t)\]

Step 3:分别更新 Critic 和 Actor。

Critic 利用 TD Error 修正状态价值估计

\[ w_{t+1} = w_t+\alpha_w\delta_t \nabla_w V_{w_t}(s_t)\]

Actor 利用 TD Error 作为 Advantage 估计，指导策略参数更新：

\[ \theta_{t+1} = \theta_t+ \alpha_\theta\delta_t \nabla_\theta\ln\pi_{\theta_t}(a_t\mid s_t)\]

GAE

GAR (广义优势估计) 是一种利用多个时间步的 TD-Error 来估计 Advantage 的方法，它是 PPO 中非常重要的组成部分。

A2C 使用一步 TD Error 估计 Advantage，而 GAE 将多个时间步的 TD Error 加权求和，得到更稳定的 Advantage 估计。

之前的 Advantage 是这样的：

\[ A^\pi(s_t,a_t)=Q^\pi(s_t,a_t)-V^\pi(s_t)\]

它表示：在当前状态执行动作 $a_t$，比按照策略正常行动的平均表现好多少。但是实际训练时，我们并不知道真实的 $Q^\pi$ 和 $V^\pi$。因此，需要估计 Advantage。

我们先定义一步 TD Error：

\[ \delta_t=r_{t+1}+\gamma V_\phi(s_{t+1})-V_\phi(s_t)\]

然后 GAE 将多个连续的 TD Error 加权求和：

\[ \hat A_t^{\mathrm{GAE}(\gamma,\lambda)}=\sum_{l=0}^{\infty}(\gamma\lambda)^l\delta_{t+l}\]

展开以后就得到

\[ \hat A_t=\delta_t+\gamma\lambda\delta_{t+1}+(\gamma\lambda)^2\delta_{t+2}+\cdots\]

这其中的 $\lambda$ 是 GAE 参数，调节使用未来 TD Error 的程度。

PPO Clip

我们已经学习过了 Policy Gradient、Actor-Critic、Advantage 和 GAE，现在再引入最后一块拼图 — PPO Clip，其核心思想就是在使用 Advantage 优化 Actor 时，避免新策略相对旧策略发生过大的概率变化，提高训练稳定性。

第一步我们引入新旧策略概率比：

\[ \rho_t(\theta)=\frac{\pi_\theta(a_t\mid s_t)}{\pi_{\theta_{\mathrm{old}}}(a_t\mid s_t)}\]

这个比值说明：新策略相对于旧策略，把这个动作的概率提高或降低了多少倍。

第二步，引入 Advantage。现在我们已经知道了新旧策略的变化程度 $\rho_t(\theta)$ 但是还不知道我们是应该提高这个动作的概率，还是降低这个动作的概率。这就需要之前学过的 Advantage：

\[ A^\pi(s,a)=Q^\pi(s,a)-V^\pi(s)\]

它告诉我们某个动作相对于当前策略的平均表现好多少。因此 PPO 可以先构造一个未经裁剪的代理目标：

\[ L^{\mathrm{PG}}(\theta)=\mathbb E_t\left[\rho_t(\theta)\hat A_t\right]\]

其中，当 $\hat A_t>0$，希望提高该动作概率，当 $\hat A_t<0$，希望降低该动作概率。

PPO Clip 的公式如下：

\[ L^{\mathrm{CLIP}}(\theta) = \mathbb E_t \left[ \min\left( \rho_t(\theta)\hat A_t,\, \operatorname{clip} \left( \rho_t(\theta), 1-\epsilon,1+\epsilon\right)\hat A_t\right)\right]\]

第一部分：原始代理目标 $\rho_t\hat A_t$。

第二部分：裁剪后的代理目标 $\operatorname{clip}(\rho_t,1-\epsilon,1+\epsilon)\hat A_t$

第三部分：取两者较小值，$\min(\text{原始目标},\text{裁剪目标})$

PPO

1. 核心思想

PPO 是基于策略梯度的 On-Policy 强化学习算法，通常采用 Actor-Critic 架构。

  • Actor：参数化策略网络 $\pi_\theta(a\mid s)$，负责动作选择。
  • Critic：状态价值网络 $V_\phi(s)$，负责估计未来累计回报。
  • GAE：利用多个 TD Error 估计 Advantage。
  • PPO Clip：通过新旧策略概率比构造裁剪代理目标，减少过大的策略更新。

2. 完整训练流程

  1. Collect Rollout：使用当前 Actor 与环境交互，记录状态、动作、奖励、终止标记、旧动作 log probability 和状态价值。
  2. Compute GAE：利用 Critic 估计的状态价值，计算 TD Error 和 Advantage。
  3. Compute Returns：根据 GAE 构造 Critic 的训练目标。
  4. Freeze Old Policy Data：固定旧 log probability、Advantage 和 Return Target。
  5. Update Actor：计算新旧策略概率比，通过 PPO Clip Loss 更新 Actor。
  6. Update Critic：最小化 Value Loss，更新状态价值网络。
  7. Entropy Bonus：通过熵正则化鼓励策略探索。
  8. Mini-Batch / Epoch：使用当前 Rollout 训练若干个 Epoch。
  9. New Rollout：结束当前优化阶段，用更新后的 Actor 重新采集数据，进入下一轮。

3. GAE 与 Return Target

\[ \delta_t=r_{t+1}+\gamma V_{\phi_{\mathrm{old}}}(s_{t+1})-V_{\phi_{\mathrm{old}}}(s_t)\]
\[ \hat A_t=\delta_t+\gamma\lambda\hat A_{t+1}\]
\[ \hat R_t=\hat A_t+V_{\phi_{\mathrm{old}}}(s_t)\]

实际计算需要处理终止状态掩码和非终止 Rollout 边界的价值自举。

4. PPO Clip

新旧策略概率比：

\[ \rho_t(\theta)= \frac{\pi_\theta(a_t\mid s_t)} {\pi_{\theta_{\mathrm{old}}}(a_t\mid s_t)}\]

裁剪代理目标：

\[ L^{CLIP}(\theta) = \mathbb E_t\left[ \min\left( \rho_t\hat A_t,\, \operatorname{clip}(\rho_t,1-\epsilon,1+\epsilon)\hat A_t \right) \right]\]
  • Advantage 为正：限制继续过度提高动作概率的激励。
  • Advantage 为负：限制继续过度降低动作概率的激励。
  • Clip 不直接裁剪网络参数或动作概率。

5. 损失函数

\[ L_{\mathrm{actor}}=-L^{CLIP}\]
\[ L_{\mathrm{critic}} = \mathbb E_t[ (V_\phi(s_t)-\hat R_t)^2 ]\]
\[ L_{\mathrm{total}} = L_{\mathrm{actor}} +c_vL_{\mathrm{critic}} -c_eH(\pi_\theta)\]

6. Mini-Batch 与 Epoch

  • Rollout：使用旧策略采集的一批经验。
  • Mini-Batch：从当前 Rollout 中选取一部分样本进行一次梯度更新。
  • Epoch：对整批 Rollout 数据进行一轮训练。
  • Iteration：通常包括一次 Rollout 采集及随后若干轮参数更新。

PPO 可以在同一批 Rollout 上进行有限次数的优化，但需要监控策略变化，不能无限复用旧数据。

7. 部署

训练阶段：

Actor + Critic + GAE + PPO Optimizer

推理部署阶段：

Observation → Actor → Action → Robot Controller

部署时通常仅导出 Actor 网络，不需要运行 Critic 和 PPO 优化器。

8. 关键超参数

参数 含义
$\gamma$ 回报折扣因子
$\lambda$ GAE 偏差—方差调节参数
$\epsilon$ PPO Clip 裁剪范围
Learning Rate Actor / Critic 优化步长
Num Environments 并行仿真环境数量
Rollout Length 每个环境每轮采集的步数
Mini-Batch Size 每次优化使用的样本数量
Num Epochs 同一批 Rollout 的训练轮数
Entropy Coefficient 熵正则化权重

总结：PPO 通过 Actor 收集数据、Critic 估计价值、GAE 计算 Advantage，再利用 PPO Clip 和 Value Loss 更新网络。完成有限轮优化后重新采样，反复迭代直到策略达到训练要求。

9. 复习

PPO 通常采用 Actor-Critic 架构。Critic 负责估计未来累计回报对应的状态价值。Critic 通过价值估计帮助计算 Advantage，Actor 再利用 Advantage 更新策略。

GAE 对多个 TD Error 进行折扣加权求和：

概念 公式 主要用途
TD Target $r{t+1}+\gamma V(s{t+1})$ 一步价值学习目标
TD Error $r{t+1}+\gamma V(s{t+1})-V(s_t)$ 衡量一步价值预测误差
GAE Advantage $\hat At=\delta_t+\gamma\lambda\hat A{t+1}$ 指导 Actor 更新
Return Target $\hat Rt=\hat A_t+V{\mathrm{old}}(s_t)$ 训练 Critic

因此其完整关系为：Critic 预测 $V(st)$ 和 $V(s{t+1})$，结合真实奖励计算 TD Error，使用 GAE
对多个 TD Error 加权求和得到 Advantage $\hat A_t$。Actor 使用 Advantage + clip，Critic 由 Advantage 构造 Return Target。

Critic 也是一个神经网络，输入当前状态，输出对未来累计折扣奖励的估计。这个神经网络的学习目标就是 ReturnTarget，由真实奖励和价值估计共同构造的学习目标。

\[ \hat R_t=\hat A_t+V_{\mathrm{old}}(s_t)\]

其中，$V_{\mathrm{old}}(s_t)$ 表示：在采集 Rollout 数据时，Critic 网络对状态 $s_t$ 预测的状态价值。
