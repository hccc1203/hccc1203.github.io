什么是 agent？以及如何搭建自己的 agent

发表于 2026-04-15 分类于 学习日志 ， AI

agent 是什么

  现在我们可以这样定义 Agent，Agent = 大模型（大脑） + 记忆系统（记忆） + 工具（手脚） + 反馈闭环（学习）。如果一个系统能做到以下四件事，就可以被称为 Agent：

  • 自主性，能根据目标自己规划下一步
  • 记忆，记住上下文、用户偏好、历史决策
  • 工具使用，能调用外部API、脚本、数据库
  • 自我修正，能根据结果调整策略、优化行为

  所以简单来说就是 大模型 + 其他能力 = Agent
