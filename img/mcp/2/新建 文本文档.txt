请帮我生成一个完整可运行的 Python 工业视觉检测项目，用于检测固定形状零件上的黄色胶带位置是否贴错。

项目目标：
使用“模板匹配 + HSV 颜色分割 + ROI 位置判定”的传统视觉方案，判断零件上黄色胶带是否贴在标准位置。要求项目可以从命令行运行，也提供一个简单的图形界面或 Web 页面用于调试图片、配置 ROI、查看检测结果。

背景说明：
工厂里有一批形状一致的零件，表面会贴多条黄色胶带。每个零件的标准胶带位置固定。现在需要检测：
1. 胶带是否缺失
2. 胶带是否贴偏
3. 胶带是否贴歪
4. 胶带是否多贴
5. 胶带是否面积不足
6. 胶带是否出现在错误区域

请不要使用深度学习，先使用 OpenCV 传统算法实现。

核心算法流程：
1. 读取输入图片
2. 读取标准模板图 template.jpg
3. 使用 cv2.matchTemplate 对当前图片进行模板匹配，找到零件整体位置
4. 根据模板匹配结果，将当前图像裁剪或映射到标准检测坐标系
5. 将图像从 BGR 转换到 HSV
6. 使用 HSV 阈值分割黄色胶带区域
7. 对黄色 mask 做形态学开运算、闭运算，去噪和填洞
8. 在配置文件中读取每条胶带的标准 ROI
9. 对每个 ROI 统计黄色像素比例、黄色区域面积、外接矩形、中心点、角度
10. 和标准参数比较，输出 OK 或 NG
11. 如果 NG，需要指出具体原因，例如：缺失、偏移、歪斜、面积不足、多贴、错误区域出现黄色胶带
12. 保存可视化结果图片，在原图上画出 ROI、检测到的黄色区域、OK/NG 状态和异常原因

请生成完整项目，而不是只给代码片段。

二、模板匹配模块 template_matcher.py
实现类 TemplateMatcher。

要求：
1. 初始化时读取模板图片
2. 使用灰度图进行 cv2.matchTemplate
3. 支持方法 cv2.TM_CCOEFF_NORMED
4. 返回匹配位置、匹配分数、匹配后的 ROI 坐标
5. 如果分数低于 template_match_threshold，返回错误状态
6. 提供 debug 可视化，画出模板匹配框

四、ROI 模块 roi.py
实现 ROI 数据结构和 ROI 检测逻辑。

要求：
1. 定义 RoiConfig 数据类
2. 支持从 YAML 加载 ROI 配置
3. 对每个 ROI 计算：
   - yellow_area
   - yellow_ratio
   - contour_count
   - bounding_rect
   - center_x
   - center_y
   - center_offset
   - angle_deg
4. 角度计算可使用 cv2.minAreaRect
5. 如果 ROI 内没有足够黄色像素，判为 missing
6. 如果黄色面积小于 min_area_px，判为 area_too_small
7. 如果中心偏移超过 max_center_offset_px，判为 position_offset
8. 如果角度偏差超过 max_angle_error_deg，判为 angle_error
9. 如果所有规则通过，判为 OK

输出格式示例：
{
  "name": "left_vertical_tape",
  "ok": false,
  "reason": "position_offset",
  "yellow_ratio": 0.43,
  "yellow_area": 2400,
  "center_offset": 24.5,
  "angle_deg": 86.2
}

六、额外黄色检测
要求：
1. 生成所有标准 ROI 的 union mask
2. 将黄色 mask 减去标准 ROI 区域
3. 统计剩余黄色面积
4. 如果剩余黄色面积超过 extra_yellow_area_threshold，则判定可能存在多贴或贴错区域
5. 输出 extra_yellow_detected = true
